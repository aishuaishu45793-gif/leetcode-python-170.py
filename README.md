# Python Programming Practice 🚀

## About This Repository

This repository contains five Python programming practice projects developed to improve my coding skills, logical thinking, and problem-solving abilities.

These programs cover basic Python concepts such as loops, conditional statements, strings, mathematical operations, and dictionaries.

## Programs Included

### 1. Sum of Digits

Calculates the sum of all digits in a given number using a while loop.

### 2. Perfect Number

Checks whether a number is a perfect number by calculating the sum of its proper divisors.

### 3. String Length Without Using len()

Calculates the length of a string without using Python's built-in `len()` function.

### 4. Celsius to Fahrenheit Converter

Converts temperature from Celsius to Fahrenheit using a mathematical formula.

### 5. Character Frequency Counter

Counts how many times each character appears in a given string using a Python dictionary.

## How to Run

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Run the Python file:

```bash
python filename.py
```

Replace `filename.py` with the actual Python file name.
